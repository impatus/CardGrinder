Native Windows installer and first public source release.

- Offline EXE installer with Start-menu entry, optional desktop shortcut and Windows uninstaller.
- Self-contained .NET 10 LTS runtime; no separate runtime installation required.
- MIT-licensed source, pinned build tools, CI tests and automated release packaging.
- QR/Steam Guard sign-in, encrypted remembered sessions and automatic sign-in at startup.
- Owned-game card discovery, selected-game queue, confirmed progress and tray controls.
- Select all, active games at the top, and bounded recovery after temporary network interruptions.

Windows 11 x64 is required. The installer and application are currently unsigned. Keep the complete folder together when using the portable ZIP.

Steam Badges HTML is undocumented and can change. Third-party automation is not guaranteed to be permitted by Valve; CardGrinder makes no VAC-safety or risk-free claim.
