Settings now includes signed update checks from impatus.no.

- Check manually for a new version and read its release notes.
- Download with progress and cancellation. Release signatures, file sizes and SHA-256 hashes are verified before use.
- Installed copies offer **Install and close CardGrinder**. Farming stops before the normal installer opens; saved login and settings are preserved.
- Portable copies download a verified ZIP and offer **Open update folder**.
- Published on impatus.no with installer, portable download and screenshot.

Windows 11 x64 is required. The runtime is included. Release signatures are separate from Windows code signing; the installer may still show an unknown publisher warning.
